# Catálogo de Produtos - Aplicação React com Vite
**Projeto desenvolvido por Chrys Penalber**

Este projeto faz parte de um exercício prático do **curso de Engenheiro Front-End da EBAC**.

O objetivo foi **desenvolver uma aplicação web moderna de catálogo de produtos utilizando React e Vite**, aplicando conceitos de componentes reutilizáveis, estado, renderização condicional e boas práticas de organização de código.

---

## Links

[**Repositório no GitHub**](https://github.com/chryspenalber/tarefa-16--react)

[**Deploy**](https://tarefa-16-react.vercel.app/)

---

## Objetivo

- Criar uma aplicação React moderna e bem estruturada
- Desenvolver componentes reutilizáveis (`ProdutoCard`)
- Aplicar conceitos fundamentais do React (props, estado, ciclo de vida)
- Utilizar **Vite** para build rápido e otimizado
- Organizar a estrutura de pastas com padrão escalável (pages, components)
- Praticar JavaScript ES6+ com JSX

---

## Estrutura de Arquivos

```text
projeto
|-- index.html
|-- src/
|   |-- main.jsx
|   |-- App.jsx
|   |-- index.css
|   |-- pages/
|   |   `-- Home.jsx
|   `-- components/
|       `-- ProdutoCard.jsx
```

---

## Componentes

- **App.jsx** - Componente raiz da aplicação
- **Home** - Página principal que renderiza o catálogo
- **ProdutoCard** - Componente reutilizável para exibir informações de produtos

---

## Pré-requisitos

- **Node.js** (v16 ou superior)
- **npm** ou **yarn**

---

## Instalação

```bash
npm install
```

---

## Execução

Para iniciar o servidor de desenvolvimento:

```bash
npm run dev
```

A aplicação estará disponível em `http://localhost:5173/`


---

## Tecnologias Utilizadas

- **React 19** - Biblioteca para construção de interfaces
- **Vite** - Bundler e servidor de desenvolvimento ultra-rápido
- **JavaScript ES6+** - Sintaxe moderna com JSX
